# Foxy model

`foxy-chibi.glb` is an original articulated Foxy robot-toy sculpt authored for this project by `scripts/generate-foxy-model.mjs`. No third-party character geometry, trademarks or animation clips are included. The earlier generated Foxy picture supplies the visual direction, not a flat plane in the 3D model.

CC0 sources considered: https://quaternius.com/packs/ultimateanimatedanimals.html (CC0, verified November 25, 2026); the generic animals do not match the original Foxy robot. Kenney and poly.pizza catalogue access was blocked. The original generated robot sculpt is used instead of a generic animal stand-in.
