# FoxGEN Pro 5.40

Install: unzip, open chrome://extensions, enable Developer mode, choose Load unpacked, then select this folder.

Use a licence key created in the Store's existing Licence Center. Licence validation and expiry are checked by https://foxgenofficial.lovable.app/api/public/license/verify. No Admin password is embedded in this extension.

The supplied feature bundles and their original service integrations remain unchanged. FoxGEN licensing does not supply credits, accounts, API access or credentials for those third-party services. Those features still require their original service access and were not tested with a live supplier account.

Changes: extension name/version, FoxGEN icons, visible branding adapter, and an exact-path licence adapter/redirect. Other FoxGEN editions are not modified.
